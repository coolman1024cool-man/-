# USR 專案預算控制表轉管考會議統計表 (USR Budget Report Formatter)

## 簡介 (Overview)
本技能用於自動化解析大學會計系統產出之 **USR 預算控制表 PDF 檔案**，並將其格式轉化為符合管考會議報告需求的 **標準 Word (.docx) 統計表**。

本技能預設嚴格遵循國家報表級別之四大規範：
1. **儲存格合併與文字去重**：第一欄「高教主軸項目」跨 22 列垂直合併為單一「USR」儲存格；第二欄分別合併「個案」與「校務」儲存格；小計與總計列自動橫向合併並置中對齊。
2. **數據優先的欄寬分配**：全表採 **A4 直式 (Portrait)**，右側數值與百分比欄位（預算、已申請未核銷、已核銷、餘額、執行率）字型設為 `10.0pt` 且開啟 `<w:noWrap/>` 防折行；第三欄「項目名稱」設為 `1.87 in`（字型 `9.5pt`）允許文字美觀折行。
3. **國家標準「標楷體」與細黑實線框線**：Word XML 底層強制指定 `標楷體` (DFKai-SB / BiauKai)；全表套用 `0.5pt` 純黑實線邊框 (`#000000`)。
4. **純黑白節能與 A4 1頁不超頁**：100% 清除背景色塊（零色塊填充節省碳粉），小計/總計整列加粗，搭配精確 cell padding 與行距，包含表末 3 項專業備註 **剛好完美收納於 A4 1 頁**。

## 快速使用 (Quick Start)

### 執行 CLI 自動轉換腳本
可以使用附帶的 Python 腳本直接執行 PDF 轉 Word 轉換：

```bash
python ~/.gemini/config/skills/usr-budget-report-formatter/scripts/convert_budget.py --pdf "D:\01邱正彥1130801-\01經費\07預算檢討會\115年上半年度\管考會議1150331\預算控制表-11503301000.pdf"
```

## 核心規範與細節 (Formatting Rules)

### 1. 欄位數據計算對照表

| 管考統計表欄位 | PDF 預算控制表對應來源 | 說明與公式 |
| :--- | :--- | :--- |
| **預算** | 可支用金額 (A) | 各子計畫/HUB之核定預算 |
| **已申請 未核銷** | 借支金額 (B) + 請購金額 (C) + 流出未核閱 (D) | 尚在請購或核銷流程中之金額 |
| **已核銷 金額** | 傳票金額 (E) | 已經會計傳票開立並核銷之金額 |
| **預算餘額** | 預算餘額 (A-B-C-D-E) | 剩餘可用預算金額 |
| **執行率** | `(已申請未核銷 + 已核銷) / 預算` | 計算至整數百分比（總計保留至小數點 1 位） |

---

### 2. 表格合併結構

- **列 0 (表頭)**：第 0, 1, 2 欄橫向合併，顯示「高教主軸項目」。
- **第 0 欄 (主軸)**：第 1 到 22 列垂直合併，單一「USR」文字。
- **第 1 欄 (類別)**：
  - 第 1 到 11 列垂直合併，單一「個案」文字（涵蓋明細與個案小計）。
  - 第 12 到 22 列垂直合併，單一「校務」文字（涵蓋明細與校務小計）。
- **小計列 (列 11, 22)**：第 2, 3 欄橫向合併，置中顯示「小計」，文字與數據全列加粗。
- **總計列 (列 23)**：第 0, 1, 2, 3 欄橫向合併，置中顯示「總計」，文字與數據全列加粗。

### 4. 常見錯誤防範 (Common Mistakes)

1. ❌ **重複字問題**：垂直合併儲存格時若未清空被合併之各格內容，Word 將產生 `USR USR USR...`。必須先呼叫 `merge()` 後，明確設定 `.text = "USR"`。
2. ❌ **金額數字折行**：未對右側金額欄設定 `<w:noWrap/>` 或欄寬不足，會導致 `$3,025,000` 折成兩行影響閱讀。
3. ❌ **頁面超出 2 頁**：未縮減 `w:tblCellMar` 上下內距或行距，表格連同備註會溢出至第 2 頁。
4. ❌ **檔案鎖定衝突**：在更新 Word 檔時，若使用者正開啟該檔案，寫入會引發 `PermissionError [Errno 13]`。處理時應先捕捉例外，或自動備份為 `_最新版.docx`。
